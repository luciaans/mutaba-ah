MUTABA'AH membantu pondok mencatat dan memantau pelaksanaan ibadah santri dengan lebih teratur. Data santri, absensi, dan laporan tersedia dalam satu aplikasi berbahasa Indonesia.

## Fitur utama

| Fitur | Kegunaan |
| --- | --- |
| Ringkasan beranda | Memantau jumlah santri, kelas, dan catatan absensi harian. |
| Absensi salat | Mencatat pelaksanaan salat per kelas, tanggal, dan waktu; alasan ketidakhadiran dapat dicatat sebagai sakit, izin, atau alfa. |
| Data santri | Mengelola profil dan status santri, mencari serta menyaring daftar, dan mengimpor atau mengekspor data melalui Excel. |
| Detail dan riwayat | Melihat profil, kalender absensi, serta ringkasan catatan setiap santri. |
| Kelas dan pembimbing | Mengelola kelas dan menentukan kelas yang dapat diakses setiap pembimbing. |
| Rekap dan laporan | Meninjau absensi menurut kelas dan periode, lalu mengunduh laporan Excel, PDF, atau Word. |
| Audit perubahan | Meninjau riwayat perubahan catatan absensi. |

## Akses pengguna

- **Admin** mengelola kelas, santri, akun pembimbing, laporan, dan audit.
- **Pembimbing** mencatat absensi untuk kelas yang ditugaskan kepadanya.

## Dibuat dengan

Next.js, TypeScript, Tailwind CSS, Supabase, ExcelJS, jsPDF, dan Recharts.
